## About Me

I am a software engineer focused on architecture, backend platforms, and AI-powered developer experience. My work is centered on building resilient systems, improving code quality standards, and creating practical automation that helps engineering teams move faster without losing technical rigor.

## Current Focus

- Working as a Senior Software Architect at Central IT, defining standards, governance, and technical direction.
- Building AI tools such as Lupa de Requisitos and Vibecoding setups for engineering automation.
- Studying cloud architecture with focus on the AWS Certified Solutions Architect Associate path.
- Expanding my work around modern Python, FastAPI, and the LangChain ecosystem.

## Engineering Profile

- Architecture first: scalability, maintainability, and resilience are design constraints, not afterthoughts.
- Developer productivity: I value workflows, tooling, and automation that reduce friction in delivery.
- Business alignment: software should solve real problems with clarity, not just add technical complexity.
- Continuous evolution: I enjoy combining solid engineering foundations with applied AI.
